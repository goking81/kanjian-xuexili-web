# 看见学习力 SEO 网站

`dna.learnbox.cc` 的正式内容网站，使用 Astro 生成静态 HTML，并部署到 Cloudflare Pages。

## 本地开发

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

构建结果输出到 `dist/`。

## 发布

- GitHub 仓库：`goking81/kanjian-xuexili-web`
- 生产分支：`main`
- Cloudflare Pages 构建命令：`pnpm build`
- 构建输出目录：`dist`
- 正式域名：`https://dna.learnbox.cc`

## 内容边界

网站用于家庭学习观察和沟通参考，不提供医学、心理或教育诊断，不预测成绩或升学结果。
