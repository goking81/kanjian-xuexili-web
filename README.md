# 看见学习力｜内容网站

面向家庭学习观察与沟通的内容网站：用文章、工具与方法，帮助家长理解孩子的学习过程，而不是给成绩贴标签。

- 正式站点：<https://dna.learnbox.cc>
- 技术形态：Astro 生成的静态网站，部署在 Cloudflare Pages
- 定位：面向 K12 / 小升初家庭的轻量内容站，强调「观察过程、沟通成长」而非诊断或预测

![看见学习力站点首页示意](docs/hero.svg)

## 这个站点做什么

把「学习力」从一个模糊的词，拆成家长能在日常里观察和沟通的维度：阅读时长、专注片段、提问质量、复述与迁移。内容以可分享的文章为主，配合少量工具页，便于在家长群、公众号和搜索里被找到。

站点不替代专业评估，也不做医学、心理或教育诊断（见下方「内容边界」）。

## 与小程序的分工

本站是产品内容站，不是浏览器测评或支付应用。测评、完整报告购买、订单查询和售后均在微信小程序“看见学习力”中完成。

- 测评与基础报告免费；本次测评的一份完整报告按需单次购买，Android / iOS 统一 29.90 元，不自动续费。
- 在服务持续提供且购买权益有效期间可重复查看，不设自动到期，不承诺永久查看；不含 PDF、人工解读或会员订阅。
- 网站同步的是产品说明，不复制小程序订单、支付签名、云函数、用户答案或报告数据库。小程序更新后，复核 `src/config.ts`、`ReportOffer.astro`、FAQ、首页结构化数据和 `public/llms.txt`。
- 对照范围与验收限制见 [2026-10-21 审查记录](docs/review-sync-20261021.md)。

## 本地开发

```bash
pnpm install
pnpm dev
```

开发服务器启动后访问终端输出的本地地址即可预览。

## 构建与发布

```bash
pnpm build
pnpm check
pnpm test
```

构建结果输出到 `dist/`。
`pnpm test` 会先构建，再检查费用/权益文案、FAQ 结构化数据、站内链接和复制失败分支；它不代替真实手机扫码、浏览器排版和付款验收。

发布链路：

| 项 | 值 |
| --- | --- |
| GitHub 仓库 | `goking81/kanjian-xuexili-web` |
| 生产分支 | `main` |
| 构建命令 | `pnpm build` |
| 构建输出目录 | `dist` |
| 托管 | Cloudflare Pages |
| 正式域名 | <https://dna.learnbox.cc> |

## 内容边界

网站用于家庭学习观察和沟通参考：

- 不提供医学、心理或教育诊断；
- 不预测成绩或升学结果；
- 所有结论以可观察、可沟通的过程为准，不以标签或分数替代理解。
