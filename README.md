# 看见学习力官网

**看见孩子怎样学习，让家庭沟通从笼统判断走向具体行动。**

看见学习力是一款面向家长与青少年的家庭学习观察工具。家长基于日常观察作答，孩子表达自己的真实感受，再把两个视角放在一起，理解学习优势、行动卡点和亲子观察差异，找到家庭可以尝试的支持方式。

本仓库维护其官方网站。网站负责产品介绍、报告样例和家长学习指南；正式测评、报告阅读、完整报告购买及订单查询在微信小程序“看见学习力”中完成。**本仓库不包含小程序源码或支付后端。**

## 适合谁，解决什么问题

主要面向希望更具体理解孩子学习状态的家庭，尤其适合小学高年级至初中阶段的家长和孩子共同使用。

| 家庭常见困惑 | 产品帮助观察什么 |
| --- | --- |
| 写作业总是拖延，只能反复催促 | 是难以启动、任务不清楚，还是遇到困难后难以继续 |
| 看起来没有学习动力 | 兴趣、目标、成功体验与选择感是否支持当前任务 |
| 家长和孩子对同一件事看法不同 | 双方回答有哪些差异，各自想到的是否是同一段经历 |
| 看完结果却不知道怎么行动 | 从一个具体任务出发，选择孩子和家长可以尝试的小改变 |

报告用于提供讨论起点，不代替对孩子真实经历的了解，也不以一次结果定义孩子。

## 从测评到报告

1. 在微信中搜索“看见学习力”，或使用下方小程序码进入。
2. 填写孩子昵称和年级，不要求填写真实姓名。
3. 家长先完成 20 题，再由孩子完成 40 题，分别表达各自的观察与感受。
4. 共同阅读免费报告，了解六维图谱、学习画像和亲子 GAP 提示。
5. 如需进一步解读，可在小程序内按需购买本次测评的完整报告。
6. 已购用户在原微信账号内查看报告，并通过“我的订单”核对购买记录。

网页版不要求填写孩子信息，不接收测评答案，也不提供浏览器付款入口。

## 报告看哪些维度

| 维度 | 观察方向 |
| --- | --- |
| 驱动力 | 兴趣、目标和成功体验如何影响学习投入 |
| 行动力 | 怎样开始任务、保持节奏并完成具体动作 |
| 理解力 | 怎样理解、组织和使用信息，表达自己的思路 |
| 抗挫力 | 面对错误和困难时怎样调整、恢复并继续 |
| 环境力 | 空间、时间、关系与反馈怎样影响学习表现 |
| 潜能力 | 已有经验与方法能否在新的学习任务中复用 |

亲子 GAP 指家长观察与孩子自评之间的差异，不是亲子关系好坏的评分，也不判断哪一方更准确。讨论差异时应回到具体情境，不凭分数推断家庭冲突或孩子的固定能力。

网站报告样例为虚构演示，不是真实用户记录；示例分数不是能力百分比或同龄人排名。

## 免费报告与完整报告

| 项目 | 内容与边界 |
| --- | --- |
| 测评与免费报告 | 完成测评后查看六维图谱、学习画像及亲子 GAP 提示，不以购买作为查看免费报告的前提 |
| 完整报告 | 本次测评的一份完整报告，Android / iOS 统一 29.90 元，单次购买，不自动续费 |
| 深入内容 | 六维完整解读、最多三组有数据支持的亲子差异、孩子行动建议和家庭沟通方案 |
| 不包含 | PDF、人工解读、会员订阅，以及后续重新测评产生的其他完整报告 |
| 查看权益 | 原微信账号内阅读；服务持续提供且购买权益有效期间可重复查看，不设自动到期，不承诺永久查看 |

- 已付款但未解锁时，先确认购买结果并查看“我的订单”，不要重复付款。

- 退款后不再享有该份完整报告的购买权益，首版不开放自动再次购买，请联系开发者核对。

购买条件和支付渠道以小程序实际页面为准。此处说明产品配置与规则，不代表已完成所有设备的实付验收；已知验证范围见[同步审查记录](docs/review-sync-20261021.md)。

## 技术与本地开发

网站使用 Astro、TypeScript、原生 CSS / 浏览器交互及 `@astrojs/sitemap`，输出静态 HTML，托管在 Cloudflare Pages。不需要部署登录、数据库或支付服务即可运行本仓库。

本地验证使用 Node.js 24 与 pnpm 11，建议使用相同版本。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

以终端输出的地址为准打开本地预览。

```bash
pnpm check
pnpm test
pnpm audit
```

`pnpm test` 会先生产构建，再检查费用/权益文案、FAQ 与结构化数据一致性、站内链接和资源、404，以及复制成功和失败分支。它不代替实际浏览器排版、微信扫码或真实付款验收。
